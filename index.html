問題文

ランナーが 街1 を出発してすべての街を巡り、街1 に戻る計画を立てています。 途中には湖などの 侵入不可エリア が広がっており、走るほど疲れがたまっていきます。 あなたは 給水機の設置位置 と 走る経路 を決め、ランナーができるだけ短い時間で巡回を終えられるようにしてください。

盤面

  • 盤面は 0 ≤ x ≤ N, 0 ≤ y ≤ N の正方形の平面です（N = 1000）。
  • 街が S 個あり、街 k の位置は整数座標 (Xk, Yk) です。
  • 既設の給水所 が W 個あり、給水所 i の位置は整数座標 (Pi, Qi) です。
  • 侵入不可エリア が K 個あり、エリア j は中心 (Cxj, Cyj)、半径 Rj の円の内部（中心からの距離が Rj 未満の部分）です。 円周上は侵入不可エリアに含まれません。円同士は重なっていることがあり、盤面からはみ出していることもあります。

給水機の設置

  • 移動を始める前に、新しい給水機を M 個まで設置できます。
  • 給水機は盤面内の整数座標に置き、侵入不可エリアの内部には置けません。街や既設の給水所と同じ位置に置いても構いません。
  • 同じ位置に複数の給水機を置くこともできますが、それぞれ 1 個として数えます。
  • 街1 は、給水機を置かない限り給水所ではありません。

移動

  • 経路は整数座標の点列 p0, p1, …, pT で表します。p0 は街1の位置で、ランナーは pt-1 から pt へ線分に沿って直線移動します。
  • すべての点は盤面内になければならず、各線分は侵入不可エリアの内部を通ってはいけません（円周に接するのは構いません）。
  • 0 ≤ T ≤ 105 で、最後の点 pT は街1の位置でなければなりません（T = 0 のときは p0 が最後の点です）。
  • 点 pt（t ≥ 0）と同じ位置にある街は訪問済みになります。出発時点で街1は訪問済みです。線分の途中で街の上を通過しても訪問にはなりません。
  • 同じ点（街・給水所を含む）を何度通っても構いません。pt-1 = pt となる長さ 0 の移動も可能です（時間はかかりませんが、その点が給水所なら給水されます）。

疲労度と時間

  • 最後に給水してから走った距離を s とすると、ランナーの疲労度は V + F·s です。出発時は s = 0 です。
  • 疲労度 x のとき、微小距離 ds を走るのに x·ds の時間がかかります。したがって、s = s0 の状態から距離 d の線分を走るのにかかる時間は次のとおりです。
    V·d + F·(2·s0·d + d2) / 2
  • 点 pt が既設の給水所またはあなたが設置した給水機と同じ位置のとき、そこで給水して s = 0 に戻ります。線分の途中で通過しても給水はされません。
  • 距離はユークリッド距離です。

給水せずに長い距離 L を走ると、かかる時間は V·L + F·L²/2 と距離の2乗で増えます。 給水所と給水機をどう使うかが鍵になります。

得点

総移動時間を Time、訪問しなかった街の数を U として、次の値が得点になります。得点は小さいほど良いです。

round(Time) + 109 × U

Time は各移動の時間を倍精度浮動小数点数で先頭から順に足した値で、最後に四捨五入します。

次のいずれかに当てはまる出力は不正（WA）です。

  • 出力の形式が正しくない（トークンが足りない、末尾に余分なトークンがある、整数でないトークンがある）
  • 給水機が M 個より多い、盤面外にある、または侵入不可エリアの内部にある
  • T が 0 ≤ T ≤ 105 を満たさない、または経路の点が盤面外にある
  • いずれかの線分が侵入不可エリアの内部を通る
  • 最後の点が街1ではない

整数は - の有無と数字だけで書いてください（+5 や 5.0 は整数として扱いません）。トークンは空白・改行で区切ります。

テストケースと総得点

  • テストケースは 100 個で、tools/seeds.txt の seed 0〜99 から生成します（tools/in/0000.txt 〜 0099.txt）。
  • 総得点は各テストケースの得点の合計です。WA のテストケースが 1 つでもあれば、提出全体を WA とします。
  • 実行時間制限は 1 ケースあたり 3 秒、メモリ制限は 1024 MiB です。

入力生成方法

rand(a, b) は a 以上 b 以下の一様な整数、rand01() は [0, 1) の一様な実数です。

  • N = 1000, V = 1000
  • F = rand(1, 10)
  • S = rand(100, 400)
  • W = rand(0, 4)
  • M = rand(1, 4)
  • K = rand(0, 40)

侵入不可エリア：確率 0.6 で既存の円に寄り添うように（半径 rand(20,100)、中心間距離が半径の和の 0.5〜1.0 倍）、 それ以外は盤面内の一様な位置に（半径 rand(20,150)）円を置きます。こうしてできる「連なった湖」が迂回を強制します。

格子点の連結成分を調べ、侵入不可エリアに阻まれない最大の領域が盤面の半分未満なら作り直します。

街：0〜8 個のクラスタ中心を作り、一部の街はクラスタの周りに正規分布で、残りは一様に置きます。

既設の給水所：一様に置きます。

擬似コード

C = rand(0, 8) 個のクラスタ (中心, σ = rand(20, 80))
ratio = (C == 0) ? 0 : rand01() * 0.8
while 街が S 個未満:
  if rand01() < ratio: p = ランダムなクラスタの周りの正規分布
  else:                p = 一様な格子点
  if p が最大の連結領域内 かつ 未使用: 採用

ローカルツール

tools/ は Rust 製で、外部クレートは使いません。

# 入力生成（seeds.txt の各行のシードから in/0000.txt ... を作る）
cd tools
cargo run --release --bin gen seeds.txt in

# 得点計算
cargo run --release --bin score in/0000.txt ../out/0000.txt

solver/ にサンプル解法があります。可視グラフで障害物を避けた最短路を求め、2-opt と Or-opt で巡回順を改善し、給水機を経路上に等間隔に置きます。
